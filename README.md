
# .github

Default community health files for all [NexusPulseTech](https://github.com/NexusPulseTech) repositories.

| File | Purpose |
| --- | --- |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Access, commit identity, branches, commit messages, pull requests |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability privately |

A repository that has its own version of a file uses that version instead of the default here.
